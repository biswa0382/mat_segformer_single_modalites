The requested channel layouts would be:

NIR: 1 channel
AoLP: 2 channels, [aolp_cos, aolp_sin]
DoLP: 1 channel
Pol: 3 channels, [aolp_cos, aolp_sin, dolp]
Thermal static: 1 frame
Thermal video: 3 frames, [first, middle, last]

A couple of data details need care:

For AoLP, confirm how the stored AoLP values encode angles, then convert that angle to cosine and sine consistently. Don’t treat the encoded AoLP image directly as an angle without checking its convention.

The example thermal_first_frame_aligned.npy appears to be a three-channel colorized image. If it is a false-color visualization rather than scalar temperature data, converting it to grayscale will not recover the thermal values. Check whether a scalar thermal source or its color lookup table is available before choosing the input representation.

Pretrained MiT weights can still initialize most of the model, but the first patch-embedding convolution has a different shape when the input isn’t RGB. You’ll need an explicit policy for adapting that layer; otherwise, its pretrained weights may be skipped.

The prepared grayscale class-ID masks and split JSON can remain as they are. The first implementation decision to settle is the exact file path and value normalization for each modality, especially AoLP and thermal.
